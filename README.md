## ما هو QRFerry؟

QRFerry يحوّل أي ملف (حتى **512 ميجابايت**) إلى بثّ أكواد QR متحركة:

- **على شاشة الإرسال**: تختار ملفاً، فيُضغط ويُرمَّز، ثم يُعرض كسلسلة أكواد QR تتغير باستمرار.
- **على هاتف الاستقبال**: تفتح صفحة `/scan` وتصوّر الشاشة بالكاميرا الخلفية، فيُفك الترميز وتُعاد بناء الملف داخل المتصفح.

**الملف لا يُرفع إلى أي خادم إطلاقاً** — النقل بصري خالص (شاشة ← كاميرا)، ما يجعله مناسباً للبيئات المعزولة أمنياً (Air-gapped).

## المزايا

| الميزة | الوصف |
|---|---|
| 🌐 **واجهة عربية كاملة + RTL** | خط IBM Plex Sans Arabic مستضاف ذاتياً بأوزان متوازنة |
| 📱 **PWA قابلة للتثبيت** | تعمل دون اتصال بعد أول زيارة (كل أصول WebAssembly والخطوط مخزّنة مسبقاً) |
| 🔒 **تشفير اختياري AES-256** | بكلمة مرور تتناقلها شفهياً؛ تصوير الشاشة لا يكفي لفك الملف |
| 🔄 **استئناف تلقائي** | إن انقطع النقل، تُحفظ رموز RaptorQ المستلمة محلياً ويُستأنف من حيث توقف |
| ⚡ **مسارات مزدوجة** | في الأوضاع السريعة يتناوب مساران ثابتان لحل ضبابية الستارة الدوّارة |
| 🧩 **RaptorQ FEC (RFC 6330)** | إعادة بناء كاملة حتى مع فقد أو إعادة ترتيب الإطارات |
| 🗜️ **ضغط مزدوج** | Brotli-11 يتسابق مع gzip-9، ويُحتفظ بالأصغر |
| ✅ **4 طبقات تحقق** | CRC لكل إطار ← كائن RaptorQ ← الحمولة ← الملف الأصلي |
| ⚙️ **Web Workers** | رسم الإطارات خارج الخيط الرئيسي فتبقى الواجهة سلسة |

## كيف يعمل؟

1. **الضغط**: تُحاول الحزمة Brotli بجودة 11 و gzip بمستوى 9 بالتوازي ويبقى الأصغر.
2. **البناء**: يُغلَّف الملف (أو نسخته المشفرة) في «حاوية بصرية» بترويسة تحمل اسم الملف ونوعه وحجمه ومجموعي CRC.
3. **الترميز**: تُقسَّم الحاوية إلى رموز، ويُنتج RaptorQ رموز إصلاح إضافية، وتُتداخل رموز المصدر والإصلاح في تسلسل البث.
4. **التأطير**: كل رمز يُغلَّف في إطار `QF4` (رأس ثنائي مضغوط + CRC-32) ويُرسَم QR خاماً (بدون توسعة Base45).
5. **الاستقبال**: يقرأ الماسح (ZXing-C++ عبر WebAssembly) رموزاً لكل لقطة، ويرفض التالف والمكرر، ويغذّي مفكك RaptorQ حتى يكتمل الكائن.
6. **التحقق والحفظ**: فك الضغط (وفك التشفير إن وجد)، مطابقة الحجم و CRC الملف الأصلي، ثم الحفظ.

## الاستخدام

1. افتح الصفحة الرئيسية على شاشة الإرسال واختر ملفاً (أو أفلته).
2. (اختياري) فعّل التشفير وحدد كلمة مرور.
3. اختر ملف ضبط الإشارة المناسب.
4. على هاتفك افتح `/scan` واسمح بالوصول إلى الكاميرا.
5. ابدأ البث وحاذِ الكود داخل الإطار حتى يكتمل الاستقبال.

## التطوير

المتطلبات: **Node.js ≥ 22.13**

```bash
npm install        # تثبيت الاعتماديات
npm run dev        # خادم التطوير (منفذ 3000)
npm run icons      # إعادة توليد أيقونات PWA
```

### الاختبارات (4 طبقات)

```bash
npm run test:codec   # اختبارات الكوديك: حاويات، ضغط، CRC، RaptorQ مع محو الإطارات
npm run build        # البناء الإنتاجي
node --test tests/rendered-html.test.mjs   # اختبارات العرض من الخادم
npm run test:e2e     # اختبارات النهاية-إلى-النهاية بـ Playwright
                     # (كاميرا محاكاة: نقل ملف كامل + تحقق بايت-ببايت + تشفير)
npm run lint         # فحص الأنماط
npx tsc --noEmit     # فحص الأنواع
```

اختبارات E2E تشغّل خادم الإنتاج فعلياً وتغذّي الماسح بكاميرا محاكاة
(canvas.captureStream) بنفس مكتبات الإنتاج: نقل ملف 400KB كامل يُسترد
بايت-ببايت، واختبار مشفَّر يرفض كلمة المرور الخاطئة ويقبل الصحيحة.

### البنية

```
app/                 # صفحات Next.js (إرسال / مسح / خصوصية)
lib/                 # البروتوكول البصري، الضغط، التشفير، الاستئناف، الرسم والمسح
worker/              # نقطة دخول Cloudflare Worker
tests/               # اختبارات الكوديك + SSR
e2e/                 # اختبارات Playwright للنهاية-إلى-النهاية
scripts/             # توليد الأيقونات وبيانات E2E
build/               # مكوّن البناء (يولّد قائمة أصول الكاش)
db/                  # Drizzle (غير مستخدمة حالياً — لا حاجة لقاعدة بيانات)
```

## النشر

المشروع يدعم منصتين، وكلاهما مجاني — **اختر الأنسب لك**:

### 🥇 Vercel (الأسهل من الهاتف)
- المشروع جاهز: ملف `vercel.json` + سكربت `build:vercel` (بناء Next.js قياسي).
- من `vercel.com` ← **Continue with GitHub** ← **Add New → Project** ← اختر
  `qrferry` ← **Deploy**.
- راجع **[دليل النشر الكامل](DEPLOY.md)** — خطوة بخطوة، من الهاتف.

### 🥈 Cloudflare Workers
- المشروع مبني أصلاً على قالب vinext، والملفات جاهزة:
  ```bash
  npm run build
  npx wrangler deploy --config wrangler.jsonc
  ```
- أو من GitHub Actions: زر **"Deploy to Cloudflare Workers"** في تبويب Actions
  (بعد إضافة سر `CLOUDFLARE_API_TOKEN`).
